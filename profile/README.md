Venora is an open-source plugin manager and API for [Fermo](https://git.sovrahi.com/oh64/fermo).

The goal is to make it possible to add plugins to Fermo without giving every plugin unrestricted access to the client or the browser.

### What we're working on

- Plugin installation and management
- A versioned plugin API
- Sandboxed plugin execution
- Permissions and capabilities
- Plugin settings and storage
- Plugin events
- Plugin UI and CSS
- Runtime limits and protections
- Developer tools and documentation

Venora is currently in **Phase 3**, where we're finishing the plugin API, runtime, browser support, and developer experience.

### Repositories

- **Venora** — plugin manager, runtime, API, tests, and bundled plugins
- **Venora-site** — project website and documentation

More repositories will be added as the project grows.

### Roadmap

**Phase 3:** Plugin system and developer experience  
**Phase 4:** Plugin registry and online infrastructure  
**Phase 5:** Maintainers and community features

Venora is currently being developed as a non-hosted plugin platform. Online services such as a plugin registry will come later.
